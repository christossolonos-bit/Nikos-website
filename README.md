# Noble Tutors UK

Private marketing website for Noble Tutors UK (online GCSE & A-level tutoring).

## Local preview

Open `index.html` in a browser, or:

```bash
npm install
npm start
```

## Deploy (Railway)

1. In Railway, **New Project → Deploy from GitHub**
2. Select this repo
3. Railway will detect Node and run `npm start`
4. Add a public domain in Railway settings
